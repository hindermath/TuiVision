# BSI-C3A-Cloud-Autonomie / BSI C3A Cloud Autonomy

**Stand / Current as of**: 2026-07-11
**Status**: `N/A`

TuiVision wählt, betreibt und benötigt keinen Cloud-Service für seine
Produkt-Runtime. GitHub und Paketregistries sind Entwicklungs- und
Lieferkettenwerkzeuge; sie ändern keine lokale Runtime-Architektur.

*TuiVision does not select, operate, or require a cloud service for product
runtime. GitHub and package registries are development and supply-chain tools;
they do not change the local runtime architecture.*

Es wird daher keine Aussage zu Portabilität, Exit-Strategie, Datenresidenz oder
Provider-Autonomie als Produkteigenschaft gemacht.

**Neubewertung / Re-evaluation**: a cloud provider/service becomes required for
build, operation, identity, data, control plane, or delivered functionality.

**Restrisiko / Residual risk**: Low while cloud use remains development-only.
