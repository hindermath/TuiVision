# BSI-C5-Cloud-Compliance-Assurance / BSI C5 Cloud Compliance Assurance

**Stand / Current as of**: 2026-09-08
**Status**: `N/A`

Es gibt keinen von TuiVision ausgewählten oder betriebenen Cloud-Service für
die Produkt-Runtime und deshalb keinen C5-Prüfbericht, Shared-Responsibility-
Vertrag oder Cloud-Operationsnachweis als Produktevidenz.

*TuiVision selects or operates no cloud service for product runtime. Therefore
no C5 audit report, shared-responsibility contract, or cloud operations evidence
is claimed as product evidence.*

TuiVision ist im aktuellen Feldtest ein nichtkommerzielles Ausbildungs- und
Beispielprojekt. GitHub, CI, NuGet und Artefakthosting sind Entwicklungs- und
Lieferinfrastruktur, keine Produkt-Cloud-Runtime. Deshalb ist kein
substantieller C5-Test erforderlich. Der Preset-Negativfall gegen unzulaessige
C5- oder Zertifizierungsbehauptungen bleibt ein Fail-closed-Sicherheitstest und
ist keine C5-Pruefung des Projekts.

*TuiVision is a non-commercial training and example project in the current
field test. GitHub, CI, NuGet, and artifact hosting are development and delivery
infrastructure, not product cloud runtime. Therefore, no substantive C5 test is
required. The preset's negative test for invalid C5 or certification claims is
a fail-closed safety test, not a C5 assessment of the project.*

GitHub-Repository-Einstellungen bleiben Provider-/Human-Evidence und werden
nicht als C5-Assurance umgedeutet. / GitHub repository settings remain provider
or human evidence and are not reinterpreted as C5 assurance.

**Neubewertung / Re-evaluation**: 2026-12-31, earlier only on commercial use,
market placement, customer handover, support contract, material cloud-service
scope, provider dependency, shared responsibility, cloud data/identity, or an
operated cloud deployment.

**Restrisiko / Residual risk**: Low under current product scope.
