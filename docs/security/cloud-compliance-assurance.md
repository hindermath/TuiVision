# BSI-C5-Cloud-Compliance-Assurance / BSI C5 Cloud Compliance Assurance

**Stand / Current as of**: 2026-07-11
**Status**: `N/A`

Es gibt keinen von TuiVision ausgewählten oder betriebenen Cloud-Service für
die Produkt-Runtime und deshalb keinen C5-Prüfbericht, Shared-Responsibility-
Vertrag oder Cloud-Operationsnachweis als Produktevidenz.

*TuiVision selects or operates no cloud service for product runtime. Therefore
no C5 audit report, shared-responsibility contract, or cloud operations evidence
is claimed as product evidence.*

GitHub-Repository-Einstellungen bleiben Provider-/Human-Evidence und werden
nicht als C5-Assurance umgedeutet.

**Neubewertung / Re-evaluation**: cloud service selection, provider dependency,
shared responsibility, cloud data/identity, or operated cloud deployment.

**Restrisiko / Residual risk**: Low under current product scope.
