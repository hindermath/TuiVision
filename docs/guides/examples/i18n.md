# I18n Beispiel / I18n Example

## Deutsch

`I18n` zeigt explizite Sprachwahl und deterministischen Ressourcenfallback.
Start:

```bash
dotnet run --project examples/I18n
```

Die Befehle zeigen den neutralen englischen Wert, die spanische Übersetzung,
einen fehlenden Schlüssel und den Fallback einer nicht vorhandenen Sprache.
Die Statuszeile nennt angeforderte und tatsächlich verwendete Sprache.
`Help -> Description` erklärt die host-unabhängige Auswahl.

Die Anwendung verwendet `TLocalizedResourceLookup` und keine Umgebungsvariable
wie `LANG`, kein `gettext` und kein Laufzeit-Extraktionsskript. Dadurch bleibt
der Nachweis auf allen Testsystemen gleich.

Barrierefreiheit: Sprache, Schlüssel, Fallback und Ergebnis sind sichtbarer
Text. Die Auswahl ist per Tastatur erreichbar.

## English

`I18n` shows explicit language selection and deterministic resource fallback.
Launch it with:

```bash
dotnet run --project examples/I18n
```

Commands show the neutral English value, the Spanish translation, a missing
key, and fallback from an unavailable language. The status line names the
requested and actually matched language. `Help -> Description` explains the
host-independent selection.

The application uses `TLocalizedResourceLookup`, not an environment variable
such as `LANG`, `gettext`, or a runtime extraction script. This keeps proof
identical across test hosts.

Accessibility: Language, key, fallback, and result are visible text. Selection
is keyboard reachable.
