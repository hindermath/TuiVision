# Mermaid-Ergänzungen und Spec-Kit-Abschlussberichte / Mermaid supplements and Spec Kit completion reports

Neue Lastenhefte erhalten bei hilfreichen Abläufen, Zuständen oder Abhängigkeiten
Mermaid-Quelltext und eine Textalternative. Nach abgeschlossenen Feature-Läufen
ist ein vollständiger Bericht im Chat und als versioniertes Markdown Pflicht.
Die neue Vorlage erklärt Ergebnis, Tests, Dokumentation, Git-Umfang, Verlauf und
Restpunkte ohne erfundene Zeitmessung oder Evidence als vermeintliche Programmlogik.

Constitution, Agent-Anweisungen und Projektvorlagen sind synchron gepflegt.
Lokale Erweiterungen und installierte Presets bleiben erhalten. Documentation
Impact: UpdateRequired, siehe docs/maintenance/mermaid-completion-governance.md.

Prüfung: Text-/Quellenkonsistenz, Agent-Parität, Mermaid-Renderprüfung und vorhandene
Repository-Gates; konkrete Ergebnisse und Merge-/Sync-Evidence folgen im PR.
Kein Produktcode geändert. Admin-Bypass ist für formale Freigaben autorisiert;
technische Fehler werden nicht als erfolgreiche Gates dargestellt.

Require readable Mermaid and text alternatives where diagrams help new intakes,

Synchronize constitutions, agent guidance and project templates while preserving
local extensions and installed presets. Reports separate actual code from generated
evidence and elapsed time from measured effort. Validate parity, semantics,
Mermaid rendering and repository gates. Documentation decision: UpdateRequired.
