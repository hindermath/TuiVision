# Sicherheitsrichtlinie / Security Policy

## Unterstützte Versionen / Supported Versions

Sicherheitskorrekturen werden für den aktuellen Stand von `main` und nach
Maintainer-Entscheidung für die neueste veröffentlichte Version bewertet.
Ältere Versionen erhalten keine pauschale Support-Zusage.

*Security fixes are assessed for the current `main` branch and, by maintainer
decision, for the latest published version. Older versions have no blanket
support commitment.*

## Sicherheitsproblem privat melden / Report a Vulnerability Privately

Bitte veröffentlichen Sie vermutete Schwachstellen nicht zuerst als öffentliches
Issue. Nutzen Sie **Security -> Advisories -> Report a vulnerability** im
[TuiVision-Repository](https://github.com/hindermath/TuiVision/security/advisories/new).

*Please do not first publish suspected vulnerabilities as a public issue. Use
**Security -> Advisories -> Report a vulnerability** in the
[TuiVision repository](https://github.com/hindermath/TuiVision/security/advisories/new).*

Der Bericht sollte enthalten:

- betroffene Version, Commit oder Datei;
- reproduzierbare Schritte oder ein minimales Beispiel;
- erwartete und beobachtete Wirkung;
- mögliche Vertraulichkeits-, Integritäts- oder Verfügbarkeitsauswirkung;
- bekannte Workarounds;
- gewünschte Namensnennung oder Anonymität.

*Include the affected version/commit/file, reproducible steps, expected and
observed impact, possible confidentiality/integrity/availability impact, known
workarounds, and attribution preference.*

## Reaktion und koordinierte Offenlegung / Response and Coordinated Disclosure

Maintainer bestätigen den Eingang, triagieren Schwere und Erreichbarkeit und
stimmen bei einem bestätigten Finding Korrektur, Tests, Release-Hinweis und
Offenlegungszeitpunkt mit der meldenden Person ab. Konkrete Reaktionsfristen
werden erst zugesagt, wenn ein menschlich verantworteter Response-Prozess
formal beschlossen ist.

*Maintainers acknowledge receipt, triage severity and reachability, and, for a
confirmed finding, coordinate remediation, tests, release notes, and disclosure
timing with the reporter. Specific response deadlines are promised only after a
human-owned response process is formally approved.*

Bitte geben Sie angemessene Zeit zur Analyse und Korrektur. Bei unmittelbarer
Gefahr für Dritte kann eine frühere koordinierte Warnung erforderlich sein.

*Please allow reasonable time for analysis and remediation. Immediate risk to
third parties may require an earlier coordinated advisory.*

## Scope und Grenzen / Scope and Boundaries

Diese Richtlinie ist ein technischer Meldeweg. Sie ist keine Zertifizierung,
Rechtsberatung, CRA-Konformitätserklärung oder garantierte SLA. Aktivierung und
organisatorische Ownership von Provider-Funktionen bleiben Maintainer-/Human-
Entscheidungen.

*This policy is a technical reporting route. It is not certification, legal
advice, a CRA conformity statement, or a guaranteed SLA. Provider feature
activation and organizational ownership remain maintainer/human decisions.*
