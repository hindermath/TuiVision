# PR Evidence: 011-port-wave2-examples

## Purpose

Port wave 2 of the mandatory Turbo Vision examples: controls, dialogs,
scrollable dialogs, dynamic dialog descriptions, lists, combo boxes, progress
bars, and clipboard flows. The feature also adds the small managed
`TScrollGroup` framework surface required by `sdlg` and `sdlg2`.

## Scope

- Production: `src/TuiVision.Controls/TScrollGroup.cs` plus eleven example
  projects under `examples/`.
- Tests: focused `TScrollGroup` tests and deterministic in-process smoke tests
  for all eleven wave-2 examples.
- Documentation: architecture evidence, security evidence, guide pages,
  `examples/README.md`, DocFX navigation, `Pflichtenheft.md`, and this evidence
  file.
- Generated documentation: `api/` and `_site/` were regenerated by DocFX.

## Accepted Limitations

The wave-2 examples preserve the historical learning purpose but do not attempt
to recreate every old rendering detail or interactive terminal nuance. The
traceable accepted-limitation and parity-cleanup records are in
`docs/architecture/architecture-risks.md`.

Interactive runtime polish is a deliberate follow-up. The current wave-2
delivery proves the ported behaviours through deterministic smoke seams and
guide evidence, while a later feature should connect those behaviours to
visible menus, command routing, desktop/status updates, and scripted event-path
smoke tests so `dotnet run --project examples/<Name>` demonstrates the same
behaviour interactively.
