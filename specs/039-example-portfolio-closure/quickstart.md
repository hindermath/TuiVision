# Quickstart: Example Portfolio Closure

## Deutsch

1. Prüfe den gebundenen Intake und den Reviewstatus.
2. Führe `ExamplePortfolioAuditIntegrityTests` aus.
3. Führe die vollständige lokale Validierungsleiter aus.
4. Vergleiche geschützte Roots mit dem Ausgangs-HEAD.
5. Setze den Closure-Status nur bei vollständig grüner Evidence.

Der Lauf verändert keine Produktsemantik. Remote-Aktionen benötigen eine neue
ausdrückliche Freigabe.

## English

Verify the bound intake and review, run the portfolio integrity suite and the
complete local validation ladder, compare protected roots with the baseline,
and record closure only after every applicable gate passes. The run changes no
product semantics and has no remote authority.
